[Goal]
A minimal Blender-style 3D viewport (infinite grid, orbit/pan/zoom, view and transform an OBJ 
model, no editing) written in C++17 with CMake, built three ways: OpenGL, Vulkan, and a CUDA 
software rasterizer. CUDA ray tracing comes after.

[Key Decisions]
{Area}	              {Decision}
Platform	          Windows, NVIDIA RTX 5080 (Blackwell, sm_120)
Editor & build	      VS Code, CMake Tools, MSVC Build Tools 2022, Ninja
Dependencies	      Only OpenGL, Vulkan SDK, and CUDA 12.8+, each optional in CMake
Windowing	          Hand-written Win32 layer, no GLFW
OpenGL	              4.6 core, hand-rolled function loader
Vulkan	              1.3+ with dynamic rendering and synchronization2
CUDA	              Software rasterizer producing a pixel buffer, shown through GL interop
Conventions	          Right-handed, Z-up, column-major, one projection function that handles GL/Vulkan 
                      clip-space differences
Grid	              Infinite plane in the fragment shader (ray-plane intersection, fwidth anti-aliasing, 
                      red/green axis lines, writes depth)

[Architecture]
Layers depend downward only: core, then platform, then scene, then renderer, then app. 
The app builds a FrameData each frame (view and projection matrices, draw list, grid parameters) 
and passes it to whichever IRenderer backend was chosen with --backend=gl|vk|cuda.

grid in Vulkan), starting with OpenGL.
